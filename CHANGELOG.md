# Changelog

All notable project changes are recorded here. Documentation delivery is not an application release.

## [Unreleased] — 2026-11-02

### Added — Phase 1 foundation preview

- Exact-pinned Next 16.4.3 / React 19.3.1 / strict TypeScript 6.0.3 foundation, Tailwind 4 and local shadcn-style Radix components.
- Navy/light/system design tokens, self-hosted Inter, responsive central/zonal/field shells and 44 workspace/account routes.
- Working navigation-only global search, theme controls, notification/account shells and honest unavailable/loading/error/retry/offline-hint states.
- Public sign-in/recovery information and visibly unapproved privacy/terms drafts; no credential collection.
- Server environment validation, process-only health/build metadata, safe logging and tested future route-access contract.
- Unit/component and production-browser viewport/keyboard/axe tests, CI definition, secret/dependency scans and route bundle baseline.
- Phase 1 version/design/environment/accessibility documentation and evidence-based completion/review report.

### Corrected during validation

- Actual ESLint peer alignment, strict environment parsing, CSP construction, mobile drawer dismissal, heading hierarchy and deterministic keyboard test setup.
- Reproducible npm 12 lockfile generation to remove npm 10/11 optional-package orphans.

No database/auth/RLS, operational submission workflows, real records, evidence storage, messaging delivery, maps, PWA/offline persistence, production deployment or recovery. Remote CI and formal accessibility review remain separate gates. Phase 2 requires approval.
